# Ihsan

Installable web app (PWA): a daily Name, searchable library of Allah’s beautiful Names, quiz with streaks, and clickable Qur’an references that open the cited ayah on Quran.com.
No build step. Plain HTML/CSS/JS.

## Run locally
    python3 -m http.server 8000
Open http://localhost:8000

## Publish free on GitHub Pages
1. Settings > Pages > Deploy from branch > main / root.
2. The app will be available at https://YOUR-USERNAME.github.io/ihsan/

## Before publishing
Have a knowledgeable teacher review the meanings, lessons and references in the `N` array in index.html.
